# GymApp — план

Личное iOS-приложение для записи тренировок в зале. Без App Store, данные только на телефоне. Дизайн минималистичный, по прототипу (скриншоты от 2026-09-29).

## Принятые решения

**Ответы на вопросы:**

| Вопрос | Решение |
|---|---|
| Стек | React Native / Expo; уверенно пишу на React/TS |
| Установка | сначала Expo Go, потом сборка через Xcode с бесплатным Apple ID; платный аккаунт — позже, если понадобится |
| Хранение данных | только локально на телефоне + экспорт/импорт JSON |
| Интеграции (Watch, Health, виджеты) | не нужны |
| Как тренируюсь | сам добавляю упражнения, собираю из них программу и назначаю её на конкретную дату |
| Что хранит программа | только упражнения и их порядок, без плановых подходов |
| Что пишем в подходе | только вес и повторы |
| Типы упражнений | вес × повторы; свой вес ± отягощение; кардио |
| Что видно в тренировке | прошлый результат |
| Графики | максимальный вес в упражнении и объём (тоннаж) по дням, неделям, месяцам |
| В зале | правки «на лету» без изменения программы; запись задним числом; тренировка без программы |
| Стартовая база | пустая: упражнения добавляю сам |
| Группы мышц | свои (название + иконка) |
| Тема | по умолчанию как в системе, с ручным выбором светлой или тёмной |
| Язык | по умолчанию как в системе, с ручным выбором русского или английского |
| Единицы | кг |
| Кнопка ♡ | открывает экран «Прогресс» |
| Таймер отдыха, калькулятор блинов | не нужны; можно добавить позже |

**Допущения — мои предложения, пока не подтверждены:**

1. **Группы по умолчанию.** При первом запуске создаются 8 групп (Растяжка, Кардио, Грудь, Спина, Руки, Ноги, Плечи, Пресс) без упражнений. Их можно переименовать или удалить.
2. **Нет кнопок «Начать» и «Завершить».** Тренировка считается выполненной, как только в ней заполнен хотя бы один подход.
3. **«Прошлый раз» подсказкой.** Пустой подход показывает серым значения прошлого раза, тап по номеру подхода подставляет их.
4. **Своя графика.** Медведь и иконки из прототипа не копируются: иконки групп и иллюстрация для пустого экрана будут свои, в том же стиле.
5. **Меню «…» в тренировке:** перенести на другую дату, переименовать, удалить.
6. **Упражнения из программы копируются в тренировку**, поэтому правки программы не меняют историю.
7. **Отягощение для своего веса хранится со знаком:** +10 — вес на поясе, −20 — помощь гравитрона.

## Требования

- **Группы мышц** — свои: название + иконка из встроенного набора. При первом запуске создаются 8 групп по умолчанию, их можно редактировать и удалять: Растяжка, Кардио, Грудь, Спина, Руки, Ноги, Плечи, Пресс.
- **Упражнение** — название, группа и тип ввода:
  - `weight` — вес × повторы;
  - `bodyweight` — свой вес ± отягощение × повторы;
  - `cardio` — время + дистанция.
- **Программа** (шаблон) — название, цвет-градиент, упорядоченный список упражнений.
- **Тренировка** привязана к дате: создаётся из программы или пустой; можно на прошедшую дату.
- **Прямо в тренировке** можно добавлять и удалять упражнения, программа при этом не меняется.
- **Подход** — вес и повторы; подсказкой показывается «прошлый раз».
- **Прогресс** (кнопка ♡) — объём по неделям и месяцам, количество тренировок. Тап по упражнению открывает графики максимального веса и объёма.
- **Настройки** (⚙):
  - тема: система / светлая / тёмная (по умолчанию — система);
  - язык: система / русский / английский (по умолчанию — система);
  - экспорт и импорт данных.

## Стек

| Что | Чем |
|---|---|
| Основа | Expo (последний SDK) + TypeScript, expo-router |
| Шторки | нативные sheet через expo-router (`presentation: 'formSheet'`, detents) |
| БД | expo-sqlite + drizzle-orm, `useLiveQuery` |
| Графики | react-native-gifted-charts |
| Градиенты | expo-linear-gradient |
| Иконки групп | свой набор SVG (react-native-svg), ~12 штук, контурный стиль как на прототипе |
| i18n | expo-localization + i18next (ru/en) |
| Прочее | expo-haptics, expo-file-system + expo-sharing, dayjs |

Версии и API нужно сверить с документацией перед установкой. Всё перечисленное работает в Expo Go.

## Модель данных

```
muscle_groups      id, name, icon, position
exercises          id, name, group_id, type('weight'|'bodyweight'|'cardio'), archived
programs           id, name, color, created_at
program_exercises  id, program_id, exercise_id, position
workouts           id, date('YYYY-MM-DD'), program_id?, name, color, created_at
workout_exercises  id, workout_id, exercise_id, position
sets               id, workout_exercise_id, position,
                   weight_kg?, reps?, duration_sec?, distance_m?
settings           key, value      -- theme, language
```

- **Упражнения копируются в тренировку.** При выборе программы на день её упражнения копируются в `workout_exercises`, поэтому история не зависит от последующих правок программы.
- **Статусов нет.** Тренировка в будущем — запланированная. Если в тренировке есть хотя бы один заполненный подход, она выполнена: на полосе недели её день обведён кружком.
- **Отягощение для bodyweight.** `weight_kg` хранит отягощение: `+10` — вес на поясе, `−20` — помощь гравитрона.
- **Упражнения с историей архивируются, а не удаляются.** Группу нельзя удалить, пока в ней есть упражнения.
- **Объём** считается как Σ `weight × reps`. **«Прошлый раз»** — это подходы из последней прошедшей тренировки с этим упражнением.

## Экраны (по прототипу)

**1. Главный экран — день**

- Заголовок «Сегодня» или название месяца, красная точка на сегодняшнем дне, справа кнопки ♡ и ⚙.
- Полоса недели Пн–Вс свайпается по неделям. Выбранный день — чёрный круг, дни с тренировками обведены.
- Ручка под полосой вытягивает месячный календарь.
- Если тренировки нет — пустое состояние со своей иллюстрацией (не медведь из прототипа) и текстом «Нет тренировок N дней».
- Если тренировка есть:
  - цветная карточка программы с количеством упражнений;
  - под ней аккордеон упражнений (иконка группы, название, шеврон);
  - в раскрытом упражнении строки подходов `№ [вес] [повторы]` крупными серыми «таблетками» с цифровой клавиатурой;
  - пустые подходы показывают значения прошлого раза серым, тап по номеру подставляет их;
  - «+ подход» и удаление подхода свайпом.
- Внизу чёрная кнопка «+» открывает библиотеку для выбранного дня; «…» открывает действия с тренировкой: перенести на другую дату, переименовать, удалить.

**2. Библиотека (шторка)**

- Сверху поиск, под ним переключатель «Упражнения / Программы».
- **Упражнения:**
  - «Создать упражнение +», ниже список групп (иконка, название, счётчик, ›);
  - группа → список упражнений → тап добавляет упражнение в тренировку дня;
  - долгий тап — редактировать или посмотреть прогресс;
  - поиск ищет по всем группам сразу.
- **Программы:** «Создать программу +», ниже цветные карточки со счётчиком упражнений.
- **Карточка программы:**
  - заголовок «Программа», кнопка ⚙ для редактирования;
  - список упражнений;
  - кнопки «←» и «Выбрать»; «Выбрать» создаёт тренировку на выбранный день.
- **Редактор программы** — название, цвет из палитры градиентов, добавление упражнений, порядок перетаскиванием.
- **Редактор упражнения** — название, группа, тип ввода. Отсюда же управляются группы: добавить или переименовать группу, выбрать иконку.

**3. Прогресс (♡)** — столбцы объёма по неделям и месяцам, число тренировок, список упражнений; тап по упражнению → графики максимального веса и объёма за месяц / 3 мес / год / всё и история подходов.

**4. Настройки (⚙)** — тема, язык, экспорт и импорт JSON.

**Визуальный стиль:**

- фон `#F7F7F7`, карточки и поля `#EFEFEF`, акцент — почти чёрный `#1C1C1E`;
- крупный жирный системный шрифт (SF Pro), скругления 16–24;
- без теней и лишних линий;
- тёмная тема — те же токены в инверсии;
- палитра программ: розовый, лиловый, красно-оранжевый, синий, фиолетовый, жёлто-оранжевый.

## Этапы

1. **Каркас.**
   - Expo + TS, expo-router.
   - Токены темы (светлая и тёмная), провайдеры темы и языка, i18next.
   - drizzle + миграции, сид групп по умолчанию.
2. **Библиотека.** Шторка, группы, упражнения, программы: создание и редактирование, иконки, градиенты.
3. **Главный экран.** Полоса недели, месячный календарь, пустое состояние, создание тренировки из программы или пустой.
4. **Тренировка.** Аккордеон, ввод подходов, «прошлый раз», добавление и удаление упражнений, меню «…». Это ядро приложения: доводим до удобства одной рукой.
5. **Прогресс.** Графики и история.
6. **Настройки и бэкап.** Тема, язык, экспорт и импорт JSON.
   - Этот этап обязателен до перехода на реальную сборку: с бесплатным Apple ID приложение переподписывается раз в 7 дней, и его удаление стирает данные.
7. **Standalone-сборка.** `expo prebuild`, затем Xcode и бесплатный Apple ID. Позже, при желании, EAS / TestFlight.

## Проверка

- Юнит-тесты (jest):
  - объём и максимальный вес;
  - выбор «прошлого раза»;
  - копирование упражнений из программы в тренировку;
  - экспорт → импорт даёт идентичные данные;
  - вычисление недели по дате.
- Ручной сценарий в Expo Go:
  1. создать группу, 3 упражнения и программу;
  2. выбрать программу на сегодня, ввести подходы, удалить одно упражнение;
  3. проверить, что программа не изменилась;
  4. создать тренировку задним числом;
  5. открыть «Прогресс» и увидеть точки на графике;
  6. переключить тему и язык;
  7. сделать экспорт → удалить данные → импорт.
